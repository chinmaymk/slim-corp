## Position Statement Format

```markdown
### {Role}'s Position on {Topic}

**Stance**: {Clear 1-sentence position}

**Reasoning**: {2-3 sentences explaining why}

**Key assumptions**: 
- {assumption 1}
- {assumption 2}

**Risk if wrong**: {What happens if this position is incorrect}
```

## Steelman Format

```markdown
#### Steelman of {Other Role}'s position
The strongest case for {their position} is: {articulate it better than they did, acknowledging the genuine tradeoff they're navigating}
```

## Objection Format

```markdown
#### Objection: {Short title}
- **Scenario**: {Concrete example where the opposing position fails}
- **Evidence**: {Why this scenario is realistic, not hypothetical}
- **Severity**: blocking | concerning | noted
- **Suggested alternative**: {What to do instead, if any}
```

## Resolution Format

```markdown
## Resolution: {Topic}
- **Decision**: {What was decided}
- **Rationale**: {Why this addresses the blocking objections}
- **Tradeoff accepted**: {What was knowingly sacrificed}
- **Mitigations**: {How the sacrificed thing is partially addressed}
- **Dissents noted**: {Any "concerning" objections that were accepted as risks}
```

## Escalation Format

```markdown
## Unresolved Tension: {Topic}

### Position A ({Role})
{Summary of position, key argument, what they're optimizing for}

### Position B ({Role})
{Summary of position, key argument, what they're optimizing for}

### Why synthesis failed
{What specific point cannot be reconciled}

### Recommended tiebreaker question for user
{A single, clear question that would resolve this tension}
```

## Decision Journal Row Format

```markdown
| {date} | {topic} | {decision} | {rationale} | {sacrificed} | {decided-by: synthesis/ceo-override/product-override/user-override} |
```
