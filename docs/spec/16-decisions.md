# 16 — Decisions

Format: decision · why · rejected alternatives.

| # | Decision | Why | Rejected |
|---|---|---|---|
| D1 | Repo files are the only state | Clone = full system; works in sandboxes; reviewable | User-global store; DB; hosted service |
| D2 | No background execution of any kind | Constraint C2 | CI curation, cron, hooks, MCP server, file watchers |
| D3 | Binary optional; protocol has a no-binary path | Constraint C3 | Mandatory binary |
| D4 | Binary never calls an LLM; returns questions | Uses the user's own agent/model; no keys; testable; deterministic | Embedded model calls; shelling to agent CLIs (deferred, D19) |
| D5 | Files = content truth; log = history + pending state | Hand edits stay legal; log never needs to replay content | Event-sourced content (fragile with hand edits) |
| D6 | Random hex IDs, collision-checked | No coordination across branches | Sequential IDs (collide on merge); content hashes (change on edit) |
| D7 | Lesson/inbox/log use git union merge | Append-mostly files; avoids conflicts for parallel branches | Default merge (constant conflicts) |
| D8 | Log rotated by year | Bounded diffs, no compaction step | Single file; size-based rotation (non-deterministic split) |
| D9 | Rule `src` holds evidence refs, not lesson IDs | Verify needs paths after lessons are gone; lesson IDs live in rule.promoted events | Lesson IDs only (loses paths) |
| D10 | Lexical similarity first; embeddings optional later | Zero deps, deterministic, small binary | Transformer embeddings (size), no similarity (dup rot) |
| D11 | Similarity only nominates; agent decides except near-duplicates | Lexical scores can't judge meaning | Auto-merge on threshold |
| D12 | `route --log` off by default | Avoid log churn on every task | On by default |
| D13 | Init seeds confirmed by the user become rules directly (c=1) | User confirmation is strong evidence; avoids empty experts | Seeds as lessons (experts start empty) |
| D14 | One active loop per repo | Simple state; avoids conflicting restructures | Per-expert loops |
| D15 | Reflect is stateless, not a loop | Runs after every task; must never block or be blocked | Reflect loop (collides with curate) |
| D16 | Decisions expire to the safe default (`distinct`) | No knowledge lost; no silent merges | Never expire (pile up); expire to discard |
| D17 | Pointers only for agent integration | Nothing to sync; no drift | Generated per-agent rule copies |
| D18 | Rules change only via explicit paths (I4) | Predictable, reviewable | Agents freely editing EXPERT.md |
| D19 | Text output default, JSON optional | Every agent reads `key: value` reliably; JSON for scripts | JSON only (noisy for agents) |
| D20 | One `always` expert (`project`) for cross-cutting knowledge | Tooling/workflow rules have no path scope; must load every task | Scope `**` on a normal expert (wins every assignment); leaving them in `_unassigned` |
| D21 | Path-evidenced lessons with no scope go to `_unassigned`, not `project` | They signal an uncovered area → spawn | Everything to `project` (spawn starves) |
| D22 | Duplicate records count only with new evidence, new actor, or >24 h | Stops confirmation inflation by one agent repeating itself | Count every duplicate |
| D23 | Split before compress | Compressing a 2×-over expert destroys knowledge | Compress first |
| D24 | Readers recover pending txns | Readers never see half-applied multi-file writes | Readers wait/timeout |

## Deferred

| Item | Revisit when |
|---|---|
| Agent-CLI sub-loops (`claude -p`, `codex exec`) as opt-in adapter | Loops need fresh-context judgment |
| Per-expert native artifacts (Claude subagents, Cursor glob rules) regenerated by `index` | Users ask for native routing |
| Multiple `.experts/` roots (monorepo packages) | Repos > ~50 experts |
| Static embeddings | Calibration shows lexical misses |
| Cross-repo expert sharing/import | Never in v1 |

## Milestones

| M | Scope | Exit criteria |
|---|---|---|
| M0 | 09, 10 as files; PROTOCOL.md; manual adoption | Used on 2 real repos for 2 weeks without binary |

| M2 | scan, init loop, curate, spawn | 15: I7–I8, L1–L13, L16 pass |
| M3 | verify, calibrate, static embeddings, migrate | All of 15 pass |
